# Crypto Quant Lab

Personal crypto quant research platform for BTC/ETH.

This repository is intentionally framework-agnostic. It borrows *design ideas* from mature open-source trading systems (fast research, realistic validation, dry-run/live separation, risk controls) but does not copy their source code.

The first milestone is a reproducible pipeline:

`market data -> strategy signal -> risk sizing -> fast backtest -> walk-forward validation -> report`

> Status: v0.1 scaffold in progress.
